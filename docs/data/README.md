# Published climate data

These files are generated by `scripts/collect.py` and consumed by the static website.

- `daily.csv`: one row per local calendar day
- `hourly.csv`: one row per local hour
- `metadata.json`: archive coverage, station details, units, and generation time

The raw one-minute archive is stored outside the published website under `data/raw/YYYY/` as deterministic gzip-compressed CSV files.
